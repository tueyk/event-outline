# 事件大纲

一个跑在 SillyTavern 里的前端扩展，把「一段有结构的剧情事件」从准备、展开到收尾都管起来：
生成大纲、让大纲一直留在模型眼前、按节点跟踪进展，全程不碰正文。

适合推理、调查、委托、探险这类有明确目标的剧情；日常闲聊用不上它。

## 它解决什么

长时间聊天里，剧情线最容易散掉：

- 设定散在角色世界书里，模型写着写着就跟设定对不上
- 线索散在几十层楼里，想推进某个事件，得先回头把所有伏笔读一遍
- 心里想好的剧情走向，聊到一半连自己都记不清，模型更记不住
- 手动把大纲贴进输入框能顶一阵，但会被上下文裁掉；事件开到一半，模型已经看不见它了

这个扩展把这几件事收进一个面板：填几个选项就能生成一份结构化大纲，
大纲自动写进世界书常驻，事件进行中随时盘点「哪些节点已经发生」，
结束后自动收尾。你只负责剧情，不负责记账。

## 功能

- **生成大纲**：填事件名（可以不填，让它自己起）、选事件类型与难度、按需调参数，
  点一下直接出一份带节点与线索的结构化大纲。它会先读角色世界书的设定再写。
- **大纲常驻**：生成的大纲写进当前角色的世界书并设为常驻，聊到多少楼模型都看得见。
  同一张卡下的不同对话互相隔离。
- **待选对比**：生成结果先进「待选」，最多同时留三份，挑一份点「采用」才生效；
  不满意直接丢弃，不留痕迹。
- **事件中盘点**：随时盘点，扩展读回大纲与最近的剧情，核对哪些节点已触发、
  哪些误导已被推翻、有没有走到大纲外，结果覆盖更新。
- **节点打勾**：可以交给模型自动判断，也可以半自动确认、或者全部自己点。
- **收尾**：完结或废弃时删掉世界书里那条大纲，历史事件按上限保留。

全程不写正文，也不替你说话：OOC 请求、大纲、盘点结果都只出现在面板里。

## 安装

把整个目录放进酒馆的第三方扩展目录，文件夹名用 `third-party-event-outline`：

```
SillyTavern/public/scripts/extensions/third-party/third-party-event-outline/
```

刷新页面，在扩展菜单里勾选「事件大纲」，再点悬浮球打开面板。

- 文件夹名要保留 `third-party-` 前缀：酒馆靠这个前缀认定第三方扩展，只有带前缀的才会在扩展面板里出现「检查更新 / 更新」按钮。改成别的名字功能照用，但更新入口不会出现。
- 目录里的 `parts/` 是开发用的源码，日常使用可以忽略，删掉也不影响运行；它跟着仓库一起分发，会随扩展进酒馆目录（约 630KB）。
- 更新：用新版本的整个目录替换即可。

## 快速上手

1. **开事件**。打开一个已绑定世界书的对话，在「生成事件」页填事件名、
   选事件类型与难度等级，其余参数保持默认就能生成。
2. **生成**。结果出现在顶部待选区，看一眼满意就点「采用」，写进世界书、成为当前事件；
   不满意点「丢弃」，或者调调选项再生成一份对比。
3. **事件中盘点**。切到「盘点」页点「开始盘点」，看哪些节点已经发生；
   也可以在设置里让它每若干楼自动盘一次。
4. **收尾**。完结或废弃，世界书里那条大纲随之删除，历史记录按上限保留。

悬浮窗拖到屏幕边缘会自动收成一条窄边，鼠标移上去展开。面板四个页签：生成事件、盘点、日志、设置。

## 主要设置

| 设置 | 说明 |
|---|---|
| 难度等级 | 事件整体强度档，默认五档；你的角色卡自带分级体系的话，可以按行填进去替换 |
| 事件参数 | 十六项细节参数，默认全部「根据当前情况自行设定」；每项都支持手打自定义说法 |
| 打勾模式 | 自动 / 半自动（模型给建议、你确认）/ 手动 |
| 记忆来源 | 自动 / shujuku 纪要 / 仅最近楼层。装了 shujuku 的纪要插件时，长对话用纪要更省 token |
| 自动盘点 | 每 N 楼自动盘点一次，填 0 关闭 |
| 转述模式 | 你的输入只是指令、AI 楼会重述剧情时打开：盘点只读 AI 楼，避免同一段剧情读两遍 |
| 读取角色世界书 | 默认打开，生成时会读角色世界书的常驻设定；关掉省 token 但生成质量会明显下降 |
| 世界书字数上限 | 默认 30000 字，设定特别多的卡可以调高 |
| 模型 API | 默认跟随酒馆主连接；也可以单独配一套，支持直连接口，每套都有「测试连接」 |
| 日志页 | 记录生成、写入、盘点、降级与报错，刷新即清空；排障先看这里 |

## 常见问题

| 现象 | 先看哪 |
|---|---|
| 面板打不开 | 扩展菜单里有没有勾选「事件大纲」；悬浮窗是不是被拖到屏幕外了 |
| 生成失败 | 日志页。常见原因：没打开对话、角色没绑世界书、模型连接不通 |
| 生成内容跟设定对不上 | 设置页「读取角色世界书」是否被关掉 |
| 生成内容漏了后半截设定 | 日志里找「世界书超出上限」，调高字数上限 |
| 盘点读不到纪要 | 设置页「当前使用」那行，看有没有黄字降级提示 |
| 详情页挂着红框说结构不完整 | 模型这次漏了字段，回生成页重新生成一份即可 |
| 大纲条目不见了 | 角色世界书里搜 `▸事件｜`；收尾时会删掉自己的条目 |
| 写完世界书在面板里搜不到 | 按一次 F5。世界书面板读的是页面加载那一刻的数据 |

## 注意事项

- **先开对话再用**：扩展只作用于当前对话，且角色必须绑定世界书，缺一条生成就会报错。
- **同一时间只跑一个事件**：开新事件前把旧的完结或废弃。
- **它只动自己的条目**：往世界书里写 `▸事件｜` 开头的常驻条目，结束时删掉，别的设定不碰。
- **写完世界书按一次 F5 再看**：世界书面板读的是页面加载那一刻的数据。在旧数据上手动改一处再保存，会把刚写入的事件条目、以及 shujuku 维护的纪要条目一起盖掉，事后还看不出是哪一步丢的。
- **盘点要花 token**：每次盘点是一次独立生成，楼层数可以在设置里调小。
