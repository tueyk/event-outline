# 事件大纲

- 版本：0.1.2（与 `src/event-outline/manifest.json` 一致，2026-11-01 起统一用代码版本号）

云酒馆（SillyTavern）的一个前端扩展。跑推理、案件、委托类剧情时，
把展开事件的准备工作收进一个面板，装上就在酒馆界面里多一个入口，不改动酒馆本体。

## 解决什么

跑案件、委托这类推理剧情时，每展开一个事件都要做三件重复的体力活：

- 把两千字左右的 OOC 词复制进输入框，再把里面的【事件名】改成这次的
- 六组体验偏好逐项手改成想要的档位，改错一项，模型就按错的难度设计整个事件
- 事件进行中，对照当初那份大纲逐条核对哪些节点已经达成

还有个更麻烦的问题：大纲只是模型的一条普通回复，聊得久了会被上下文裁掉，
事件开到一半大纲已经不在模型眼前，盘点只能靠它「回忆」。

## 做了什么

一个悬浮在酒馆界面上的面板，四件事：

- **生成事件**：填个事件名，选好这次的体验偏好，点一下就直接出大纲。
  不用再复制粘贴、不用再逐项改字。它会读角色世界书的设定再写，
  你也可以手填这个事件想达成什么、大致框架是什么。
- **大纲常驻**：生成的大纲自动存进当前角色的世界书，设为常驻，
  聊到多少楼模型都看得见。同一张卡下的不同对话互相隔离，不会串。
- **盘点**：事件进行中随时盘点，扩展读回大纲、推演状态和最近的对话，
  核对哪些节点已触发、哪些误导被推翻、有没有走到大纲外。结果覆盖更新，
  不会越攒越多。
- **打勾**：节点达成与否可以由模型自动判断，也可以完全你自己点。

全程不写正文，也不替你说话。正文区从头到尾只有正常对话，
OOC 请求、大纲、盘点结果都只出现在面板里。

## 怎么用

### 前置条件

用之前先确认三件事，缺一条就会卡住：

| 条件 | 不满足时 |
|---|---|
| 已经打开一个对话 | 生成时报「请先打开一个对话」 |
| 角色绑定了主世界书 | 生成时报「当前角色未绑定世界书」 |
| 扩展已启用 | 菜单入口和悬浮窗都不会出现 |

### 完整流程

打开面板 → 填事件名 → 选事件类型与偏好 → 生成 → 事件中盘点 → 收尾。

面板是四个页签：生成事件、盘点、日志、设置。悬浮窗贴边后会自动收起成一条窄边，
鼠标移上去展开。

**第一步，开事件。** 在「生成事件」页填这些东西：

- **事件名**：可以留空。留空时 AI 会读当前剧情，自己起一个 4-12 字的名字
- **事件类型**：主类型单选（案件推理、谈判交涉、探险探索、生存危机、社交博弈、
  战斗冲突、日常委托、禁忌秘辛），次类型多选至多三个（悬疑、复仇、背叛、失踪、
  盗窃、走私、政治阴谋、超自然、瘟疫、营救、交易、追捕、守护、潜入、解谜、人情）。
  两者都可以不选，不选就是「根据当前情况自行设定」
- **体验偏好**：十七项，默认全部「根据当前情况自行设定」
- **事件目的**：你想让这个事件最终达成什么。留空则由 AI 按当前剧情自行判断。
  填了会作为硬约束，大纲的核心真相与推进路径都围绕它展开
- **事件框架提示**：你自己构思的大致框架、想要的桥段或细节。留空则由 AI 完全设计。

十七项里有四项直接决定事件形态，和难度无关，可以单独定：

- **节点数量**：少（4-6 个）/ 中（7-9 个）/ 多（10-14 个）。节点越多推理越绵密，
  但盘点时要逐个勾选，负担也更大
- **参与者规模**：这次事件牵扯多少人。人越多线越多，但每个角色的戏份会被摊薄
- **节奏结构**：单点突破（找到关键即结束）/ 多层递进（逐层揭开）/ 并行多线（几条线索交替）
- **与前事关联**：完全独立 / 承接已有线索 / 主动留下后续伏笔

体验偏好分三组折叠，每组都能切「大致 / 详细」：大致就是选一个粗档位一次定好，
详细才逐项挑。难度等级一旦选定具名档位，下面三组里的「自行设定」会自动变成
「根据难度等级自行设定」，模型会按那个等级成套推导难度，不会各说各话。

难度等级默认五档：日常琐事、小麻烦、正经事件、重大危机、生死关头。
这套档位只描述事件本身有多难多危险，不绑定任何世界观。如果你的角色卡自带
一套分级（比如 F 到 SSS、或「见习 / 正式 / 精英」），到设置页「难度档位」
里每行一个填进去，下拉框就会换成你那套说法。

「事件目的」和「事件框架提示」冲突时的处理：目的优先保证，因为那是你真正
想要的结果；框架提示在跟结构完整性冲突时会让步，先保证信息节点都能拿到。

**生成之后先进待选，不直接生效。** 生成的结果会放在页面顶部的待选区里，不会写进世界书，
也不会打断正在进行的事件。看看满意就点「采用」，这时才写入世界书并成为当前事件；
不满意点「丢弃」即可，什么都不会留下；也可以调一调选项再生成一个来对比，
三个待选可以并存。选项会停在生成时的那一份，想全部回默认就点「重置为默认」。
详见下面的「待选事件」。

**第二步，事件中盘点。** 切到「盘点」页点「开始盘点」。扩展会读回大纲、拉取记忆、
取最近若干楼对话，核对哪些节点已经触发、哪些误导被推翻、有没有走到大纲外。
结果覆盖更新，不会越攒越多。

除了手动点，也可以让它在固定楼数后自动跑一次。设置页有「自动盘点间隔」，
默认每 10 楼触发一次，填 0 关闭。只有存在进行中事件时才会跑。

盘点时会显示分步进度：读记忆、拉楼层、请模型、解析结果各占一行，
带每步耗时和总用时。卡住一眼能看出来是哪一步。

生成大纲时也一样有进度条，就显示在「开始生成大纲」按钮下面。

节点清单上直接点就能手动改判。把已经勾上的撤掉，会记进否决列表，自动模式
不会下次又给你勾回来。

**第三步，收尾。** 完结或废弃都会删除世界书里那条大纲。历史事件卡按上限保留
（默认完结 20 条、废弃 3 条），超出时按结束时间从旧到新清掉最老的，
进行中的事件永远不会被清。

### 待选事件

生成不会直接改写世界书，也不会打断正在进行的事件。结果先进「待选」，
你可以一次生成几个挑一个最好的。

每个待选项显示事件名、节点数、角色分类数和简介，三个按钮：

- **采用**：写入世界书，成为当前事件。如果已有事件在进行中，会提示先完结或废弃它
  （同一时间只有一条世界书大纲生效）
- **丢弃**：直接删掉。没写过世界书，所以不会留下任何东西
- **看大纲**：展开完整大纲，方便几个待选对比

最多同时保留三个，超出时最早生成的会被挤掉，日志里会记一行。

待选只存在当前对话的记录里，刷新页面还在，不会写入世界书。
真正占世界书位置的只有「采用」之后的那一条。

### 世界书怎么参与生成

生成大纲时，扩展会读角色绑定的那本世界书，把设定类条目拼进提示词。
不读的话，模型只看得到对话和纪要，写出来的东西容易跟设定对不上。

这个开关在设置页「读取角色世界书」，默认打开。关掉能省几个 token，
但代价是生成质量明显下降，一般不建议关。

不是所有条目都会读，只挑「蓝色的常驻设定条目」。以下会被剔除：

- 绿色的关键词触发条目（它们按关键词激活，不该整本塞进 prompt）
- 本扩展自己写的事件大纲条目（`▸事件｜` 开头）
- shujuku 导出的表格副本
- 变量格式说明、变量列表这类给插件看的条目
- 含 EJS 模板语法的条目（`<% ... %>`，那是动态计算的，取不到真实内容）

设置页可以调字数上限，默认 30000 字。超了会按顺序截断，后面的条目带不进去，
日志里会有警告。设定特别多的卡可以调高，但注意这直接吃上下文。

生成前「上下文预览」会显示这次实际带了多少字的世界书内容。

### 打勾模式怎么选

三档，在设置页切换：

| 模式 | 模型判出节点后 | 适合 |
|---|---|---|
| 自动（默认） | 直接写入，同时更新误导与大纲外路径 | 想省事、信任模型判断 |
| 半自动 | 记进待确认列表，盘点页「待确认的建议」列出来，你点确认才写入 | 想让模型先给意见、自己把关 |
| 手动 | 不写入，只留报告 | 完全自己掌控节奏 |

三种模式下手动点节点都有效。

### 记忆来源怎么配

记忆来源决定盘点时喂给模型「过去发生了什么」。三种选择：

- **自动（默认）**：按优先级探测，当前对话有 shujuku 纪要就用纪要，没有就退回最近楼层
- **shujuku 纪要**：指定用纪要表。这套数据比原始楼层精炼得多，每条带编码、
  时间跨度、概览和正文，适合长对话
- **仅最近楼层**：不管纪要，直接取最近若干楼的原文

手动指定但检测不到数据时会自动降级，设置页用黄字提示你降到了什么。
纪要表按名字「纪要表」识别，换了模板也不会静默失效。

「最近楼层」决定取多少楼，默认 15，范围 1-100。这个数字直接决定盘点花多少 token。

### 模型 API 怎么配

默认「跟随酒馆主连接」，就是用酒馆当前选的模型，不用配。想另外配，设置页
「新建配置」，每套配置三选一：

| 方式 | 走什么 | 要填什么 |
|---|---|---|
| 跟随酒馆主连接 | 酒馆当前连接 | 什么都不用填 |
| 走酒馆连接源 | 酒馆里已配好的连接 | 连接源类型（12 种）、模型名、输出上限 |
| 直连接口 | 扩展自己请求你填的接口，与酒馆主模型完全独立 | 接口地址、密钥、模型名、温度、输出上限 |

每套配置都有「测试连接」，点一下会发一条极短的请求，回报耗时和返回内容，
不用等到生成失败才知道配错。

直连有两个要注意的：一是接口必须允许跨域（CORS），否则浏览器会拦住；
二是密钥存在酒馆的扩展设置里，和酒馆自己存 API 密钥是同一个位置，没有额外加密。

### 日志页怎么看

「日志」页顶部是扩展运行日志，记录扩展做过的事：挂载、读写世界书、记忆适配器判定、
生成与解析、打勾变更、报错。只存在内存里，刷新即清空，不会写进聊天记录。

按级别分四档，标题下面有筛选按钮，每个带实时条数：

| 级别 | 记什么 |
|---|---|
| 信息 | 用户关心的结果：生成成功、盘点完成、世界书写入、事件收尾 |
| 警告 | 能继续但要注意的降级：适配器降级、模型没按格式返回、世界书被截断 |
| 错误 | 真失败：生成/盘点失败、世界书校验不通过、解析不出任何节点 |
| 调试 | 排障细节。**默认不收集**，要去设置页打开「调试日志」开关 |

出现警告或错误时，日志页签上会挂一个红色数字，提示有几条没看过。
切到日志页就清零。生成或盘点时如果哪里不对，这里能第一时间看到，
不用等结果出来才发现问题。

### 出问题先看哪

| 现象 | 先看哪 | 常见原因 |
|---|---|---|
| 面板打不开 | 扩展菜单有没有「事件大纲」 | 悬浮窗被拖到屏幕外，或悬浮窗开关关着 |
| 生成失败 | 日志页 | 没开对话、角色没绑世界书、模型连接不通 |
| 生成的东西跟设定对不上 | 设置页「读取角色世界书」是否打开 | 开关被关了，或世界书里没有常驻的蓝色条目 |
| 生成的东西漏了后半截设定 | 日志页找「世界书超出…上限」 | 字数上限太小，后面条目被截断，调高即可 |
| 节点清单为空 | 日志页 | 模型返回的 YAML 超出解析器支持范围 |
| 详情页挂着红框说结构不完整 | 红框里列出的缺失项 | 模型这次漏了字段或节点，节点进度会跟踪不准；回生成页重开一次事件即可 |
| 盘点读不到纪要 | 设置页「当前使用」那行 | 指定的来源无数据，已黄字降级；或表名不是「纪要表」 |
| 没有 shujuku 诊断 | 记忆来源那一项 | 只有来源解析为 shujuku 纪要时才显示，刻意设计 |
| 大纲条目不见了 | 角色世界书搜 `▸事件｜` | 收尾时删了，或被别的工具整本覆盖 |
| 日志页签有红色数字 | 点进日志页看警告和错误 | 有没看过的异常，数字是未读条数 |
| 进度条停在某一步不动 | 看停在哪一步 | 卡在「请模型」就是模型接口慢或不通 |

顺序是：日志页 → 设置页状态行与自检 → 浏览器 console。

## 注意事项

- **先开对话再用**。扩展只作用于当前打开的对话、且角色必须绑定了世界书，
  两点缺一，生成会直接报错。
- **同一时间只跑一个事件**。开新事件前先把旧的「完结」或「废弃」，
  否则新的会顶掉当前事件的位置。
- **它会往角色世界书写一条** `▸事件｜` 开头的常驻条目，完结或废弃时删掉。
  只增删自己的条目，别的设定一个字不动；但如果你的世界书开在旁边编辑，先关标签页。
- **盘点要花 token**。每次盘点是一次独立生成，读回大纲 + 纪要 + 最近楼层，
  楼层数在设置里能调小。
- **正文区不会出现任何东西**。如果你在正文里看到了 OOC 文本或大纲，
  那是手动的旧流程留下的，不是这个扩展干的。
- **还缺的功能**：向量/交火模式的专项召回、世界书快照的还原入口。
  已经能用的：模型 API 单独配置（含直连接口）、半自动模式的建议确认。
